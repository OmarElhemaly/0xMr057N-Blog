# 0xMr057N | Security Research

A personal cybersecurity blog focused on web application security, penetration testing, vulnerability research, and practical tooling.

**Live site:** https://omarelhemaly.github.io/0xMr057N-Blog/

## Publish a new post

1. Open the repository's `_posts/` directory.
2. Create a Markdown file named `YYYY-MM-DD-your-post-title.md`.
3. Add the front matter shown below, then write your article in Markdown.
4. Commit to `main`. GitHub Actions builds and deploys the site automatically.

```yaml
---
layout: post
title: "Your article title"
date: 2026-11-17
categories: [Web Security, Writeups]
tags: [sqli, burp]
description: "A short summary for search and previews."
---
```

Only publish writeups for labs, systems, and targets you are authorized to test.
